# SHTOPOR

SHTOPOR is a retro first-person shooter set in 1990s Japan.

The game focuses on fast-paced combat, exploration, and clearing levels from enemies while finding key cards and interacting with the environment.

The project is currently in the prototype stage and may grow with new mechanics, weapons, enemies, and levels in the future.

## Features

- First-person movement and wall jumping.
- Melee combat and firearms.
- Multiple weapons with primary and alternative attacks.
- Health, armor, and ammunition systems.
- Multiple enemy types.
- Interactive doors, buttons, and objects.
- Red, green, and yellow key cards.
- Pickups: health, armor, ammunition, and weapons.
- Secret areas and gameplay puzzles.
- Multi-level progression.
- Retro 1990s Japan setting.

## Technologies

- [Unity](https://unity.com/) — game engine.
- [C#](https://learn.microsoft.com/en-us/dotnet/csharp/) — programming language.

## Running the Project

1. Install [Unity Hub](https://unity.com/download) and the Unity Editor version used by the project.

2. Clone the repository:

```bash
git clone https://github.com/st9265742-afk/HammerTeam-Project.git
```

3. Open the project in Unity Hub.

4. Open the main scene and press **Play** in the Unity Editor.
